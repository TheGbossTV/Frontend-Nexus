## Introduction

Zustand (German for "state") is a state management library from the pmnd.rs
team. Current major version: **v5**.

The whole idea is that a store *is* a hook. You call `create` with a function
that receives `set`, and you get back a hook you can call from any component —
no `<Provider>` wrapper, no context, no reducers or action-type constants.

```js
import { create } from 'zustand'

const useCounterStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}))
```

Consuming it is a hook call. The argument is a **selector** — the function that
decides what this component actually cares about:

```jsx
function Counter() {
  const count = useCounterStore((state) => state.count)
  const increment = useCounterStore((state) => state.increment)

  return <button onClick={increment}>Clicked {count} times</button>
}
```

That selector is the important part. A component that selects only `count`
re-renders only when `count` changes — not when some unrelated slice of the
store updates. This is the main practical difference from putting the same
object into React Context, where every consumer re-renders on every change.

Note that `set` **merges** at the top level rather than replacing, so returning
a partial object is normal and you don't need to spread the rest of the state.

## Things worth knowing early

State lives outside React, so you can read and write it from anywhere — event
handlers, plain functions, other libraries — using the store's static methods:

```js
useCounterStore.getState().count
useCounterStore.setState({ count: 10 })
```

When you need more than one value at once, selecting an object literal creates a
new reference on every render, which defeats the re-render check. Use
`useShallow` to compare the selected fields instead of the object identity:

```js
import { useShallow } from 'zustand/react/shallow'

const { count, reset } = useCounterStore(
  useShallow((state) => ({ count: state.count, reset: state.reset })),
)
```

Everything else — persistence to `localStorage`, Redux DevTools, Immer-style
mutable updates — is opt-in middleware from `zustand/middleware` that wraps the
same store function.
